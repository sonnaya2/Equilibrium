# GUI concepts tournament — CEO rubric

Pass bar: **one concept ≥ 9.0 / 10**. Default **3 rounds**, extend to **5** if needed.
Product: RS3 Equilibrium. Class: game-world surface + tool workbench.
Binding law: `equilibrium-ui`, `no-slop-ui` §§1–4.5, `data-readability`, `bot-audit`.

## Weighted axes (100 pts → /10)

| Axis | Weight | 9+ means |
|---|---|---|
| Workbench fill | 20 | ≥70% content @1440p; no blog-column primary; internal scroll regions |
| Categorization | 20 | Heavy routes tabbed/submenued; inactive panels not mounted |
| Readability | 15 | Data ≥14px, labels ≥11px, key ≥20px; head-still; contrast ≥4.5:1 |
| Game identity | 15 | Gem chrome, gold titles only, crests/icons, carved panel — not sterile |
| Anti-slop | 15 | No hero/SaaS/rainbow/glow-at-rest; bot-audit PASSES |
| Operability | 10 | Focus, reduced-motion, frozen e2e feasible, map ledger owns a11y |
| Consistency | 5 | One shell + tab pattern across routes |

## Hard fails (score capped ≤6)

Marketing hero · EverSense pink/Print · order-blue chrome · gold as active nav ·
cloned third-party tool layout · invented numbers presented as real ·
breaking frozen e2e strings without paired e2e update.

## Round protocol

1. Three divergent concepts (Lattice Bench · War Table · Control Surface).
2. Each ships a lab mock on `/concepts` + ASCII IA for all six routes.
3. CEO scores, writes verdicts on the lab scoreboard.
4. Pass if any ≥9.0. Else must-fix list → next round.
5. Rounds 4–5 may hybridize top axes under an explicit hybrid brief.
