## Thesis

Combat is the product’s math room. CALC CRYSTAL treats it as a **cut-gem ability desk**
inside an **Editorial fort** — not a cyber dashboard and not a marketing calc widget.

1. **Crystal facet ability desk** — style filters with real combat icons, slot bar as
   facet cells, dense ability scan. Gem chrome owns every interactive active state.
2. **Editorial panel craft** — magazine rails, gold engraved titles only, wiki-dense
   tables, masthead discipline on non-combat routes.
3. **Honest vacancy** — empty DPL / adren / unbound setup are **structured vacancies**
   (labeled `—` wells, vacancy captions). Never invent Damage Potential, never fill
   adren with demo math, never fake kill-time.
4. **Recipe complete** — Overview Daylight courtyard, Data 3-col Lattice+sources,
   Map Editorial board without inspector bloat, Tasks Crystal×Data, Build Editorial
   with crests + honest relic empty tiers.

Recipe is fixed. Forge wins on **execution of Combat as masterpiece** while every
other route still hits its DNA.

## Combat signature (must read as masterpiece)

```
[ Quick | Setup | Analysis | Rotation ]
[ style icon chips: All · Melee · Magic · Ranged · Necromancy · Defence ]
[ facet ability bar — real icons when available — 5 slots ]
[ wiki-dense ability table | editorial inspector with vacancy wells ]
```

### Vacancy law (hard)

| Field | Empty presentation | Forbidden |
|---|---|---|
| Damage Potential | Vacancy well: glyph `—` + caption `Unbound · no target math` | Fake % from “demo” |
| Adrenaline | Vacancy well: `—` + `Unbound · ability cost/gain empty` | Invented +15 / −50 |
| Hit / expected | Structured empty row in Analysis | Kill-time, enrage, boss phase |
| Blessings / league mult | Empty until revealed | Stub tier numbers |

Fixture ability **names and styles** are real RS3 catalog labels for scan density.
Math columns stay vacant until the live combat core binds.

### Style filters

Use `styleIconPath` / `/game/combat/*-abilities.png` and ability PNGs under
`/game/combat/abilities/<style>/`. Crests from `regionCrestPath`. Keyart from
`/brand/keyart-2026.jpg` only. No gen-AI.
