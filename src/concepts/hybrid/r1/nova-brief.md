## Thesis

**Courtyard First.** The product is a premium public companion site that opens on a fort courtyard gate: the 2026 keyart is architecture, not a marketing strip. The **Editorial token spine** (deep void, magazine mast, wiki stage, gem active, gold titles) runs every other route so the site never splits into “pretty Overview / brown console rest.”

Nova wins when:

1. Overview’s three-bay gate (standing picks · keyart aperture · milestones) reads as public-site craft under Editorial ink.
2. Map is an editorial wartable (perspective board + full 11-crest gazetteer) with **zero** side inspector.
3. Data is a real three-column desk: Daylight browse · lattice table · full sources on the right.
4. Tasks/Combat carry Crystal facet language without mint-washing Editorial body ink.
5. Build presents relics as carved editorial cards — empty envelopes stay empty.

Not a SaaS funnel. Not a developer console. Not gen-AI art. Fixture rows always labeled **fixture**.

## Per-route DNA

### Overview — Daylight courtyard gate

```
┌─ LINTEL (gold title · fixture meta) ─────────────────────────────────┐
├─ WEST JAMB (3 standing pick posts) │ APERTURE (keyart) │ EAST (milestones) ─┤
└─ COURTYARD DESK (plan ledger + next board · slate panels) ───────────┘
```

- Keyart: `/brand/keyart-2026.jpg` inside the aperture, not a full-bleed hero.
- Live pick state from shared Build/Map loadout.
- No CTA funnel, no feature-card garden.

### Map — Editorial 3D-top · no inspector

```
┌─ toolbar: gazetteer · N/3 · Clear picks ─────────────────────────────┐
│  perspective board mock (horizon + slab grid)                         │
│  11 crest tiles on the board (pick + focus on-card)                   │
│  folio strip UNDER board (not a right rail inspector)                 │
└───────────────────────────────────────────────────────────────────────┘
```

- Real crests: `/game/regions/{id}.png`.
- Cap 3; 4th pick disabled; Clear always present.
- No side inspector column — recipe hard rule.

### Tasks — Crystal facets × Data density

- Facet chips (All / Easy / Medium / Hard / Elite) with count pips.
- 15px sticky table, zebra stage, checkbox done state, crest cells.
- Compact facet inspector (task detail) — denser than casual cards.

### Build — Editorial + relic presentation

- Segments: Regions · Relics · Blessings.
- Regions: live pick lattice with crests, `0/3` / `3/3`, aria-disabled 4th.
- Relics: seven tier cards — revealed slots use carved editorial presentation; unrevealed stay empty copy (never invent).
- Blessings: empty envelope until official reveal.

### Combat — Crystal main

- Segments: Quick · Setup · Analysis · Rotation.
- Style chips with combat icons; ability sample table.
- Result bay: structured empty (DPL / hit cap unbound) — style bound only.
- Facet panel language, Editorial stage under tables.

### Data — Lattice + Daylight browse + full sources

```
[ Lattice tabs: Browse | Progression | Unlocks | Systems ]
┌─ Daylight browse rail ─┬─ dense table ─┬─ RIGHT source inspector ─┐
│  region/track leaves    │  15px body    │  gold title · key figure │
│  crest + counts         │  fixture tags │  FULL SourceReference    │
└─────────────────────────┴───────────────┴──────────────────────────┘
```

Inspector must show: title, region crest, kind, track, qty, status, **sources?** block with label, URL/path stub, verified date pattern, notes — not a single grey caption.
