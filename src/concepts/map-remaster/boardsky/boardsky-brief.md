# Team Boardsky — Deep Board Sky

Pure Hybrid DNA remaster of production Board Sky composition. Lowest layout risk; highest craft bar.

## Thesis

Ship tomorrow’s map by finishing the stack the product already promised: board is the majority, ledger and detail live under it, and quality lives in materials — not a new IA.

## Must sell

1. **True Board Sky** — full-width board top; horizontal ledger chips + dossier under; zero side inspector.
2. **Brighter table** — readable terrain grain at rest (no mud void).
3. **Selection** — focused slab stays elevated with gem rim; dim peers, not mint-wash.
4. **Seam vines** — tube-read plant borders on land seams (highlight + core + shade), not corner ribbons.
5. **Water** — multi-band directional swell + foam ridges (not two soft teal blobs).
6. **Pin dossier** — place pin expands map-chip dossier (content + drops); no pin → region stub.
7. **Ledger** — horizontal chips with region names + `FIXTURE_PICKS` pick counter (`1/3` fixture start).

- Three.js / WebGPU — CSS/SVG lab mock only.
