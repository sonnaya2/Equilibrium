# Map remaster — CEO rubric

Pass bar **9.0**. Hardass. Fixture mocks, not production WebGPU.

## Scoring (0–10 each, equal weight)

1. **Brightness** — Can you read terrain grain at rest? Or is it still mud?
2. **Selection** — Framed region stays elevated and clearly brightest without mint-washing the whole cap.
3. **Vines** — Read as 3D plants on **land borders** (not viewport corners, not flat neon wire).
4. **Water** — Animated sea that reads as water; not two soft teal blobs.
5. **Pin dossier** — Marker → content + drops (or honest empty). Dense, game-tool, not a modal carnival.
6. **UI shell** — Board primary; detail under/transient. No permanent third inspector column. Ledger a11y still imaginable.
7. **Craft / anti-slop** — Editorial tokens, no SaaS glass, no rainbow glow, no marketing hero.
8. **Remaster feel** — Would you ship this over today's production map?

## Hard fails (cap score ≤ 7.5 regardless)

- Side inspector column as permanent layout
- Flat ribbon sold as “3D vines”
- Invented drop tables as fixture facts
- Gen-AI art
- Photo plate as the war table itself
- Unreadable dark board

## Champion

Highest mean. Ties broken by (1) selection clarity (2) vine 3D read (3) Board Sky fidelity.
